# Asri & Neha — Birthday Website

A responsive birthday website recreated from the supplied screen recording's visual flow.

## Included sections
- Birthday hero for Asri
- Interactive "Press for a memory" camera reveal (uses the five supplied photos)
- Interactive cake-cutting moment
- "Us, in pictures" gallery
- Make-a-wish candle interaction with floating confetti
- Personal letter signed by Neha
- Six tap-to-reveal wishes
- Final birthday message

The "Press play for me" music section has been removed as requested.

## Run
Extract the ZIP and open `index.html` in Chrome, Edge, or Firefox. No installation or build step is required. Internet access is only needed for the Google Fonts import; system fallbacks are included.

All five provided photos are stored locally in `assets/`.
